# Governance

The repository currently has one primary maintainer: `chohcx`.

The primary maintainer approves tariff versions, releases, security policy, and changes to supported providers. Automation may detect changes and prepare evidence, but it cannot publish tariffs or releases without human approval.

Decisions that change data ownership, privacy defaults, public API contracts, or tariff semantics must be recorded in repository documentation before merge. If additional maintainers join, this document will define nomination, review, and removal procedures before they receive release authority.
