# 台灣水電費分攤工具 / TW Utility Kit

一個在瀏覽器端執行的水費與電費分攤工具。輸入實際帳單總額與各房間前後期分表讀數，即可按照實際用量比例分攤費用。帳單與歷史紀錄只保存在瀏覽器的 `localStorage`，應用程式不會將這些資料上傳伺服器。

[線上使用](https://chohcx.github.io/electric-bill/)

## 適用情境

- 分租套房或共用水表、電表
- 室友按各自分表用水量或用電量分攤同一張帳單
- 依實際戶數增減分表，並自訂房號、租客代號或空間名稱
- 需要備份、還原與複製分攤明細

本工具是「實際帳單金額分攤器」，不是台電、台水或北水的官方費率試算器。它不會重算累進費率、基本費、時間電價、公共用電、污水費或其他帳單項目；使用者應先確認輸入的帳單總額正確。

水費依供水區可能由台灣自來水公司、臺北自來水事業處或其他事業單位計收，帳單組成也不完全相同。因此首版刻意以實際帳單總額為準，避免提供錯誤的官方費率估算。

## 分攤規則

1. 每房用量為「本期讀數 − 上期讀數」。
2. 帳單按各房用水量或用電量占總用量的比例分攤。
3. 金額以新臺幣整數分配；不足一元的尾差依小數餘額由大到小分配。
4. 所有房間的分攤金額加總必定等於四捨五入後的帳單總額。

## 本機執行

這是無需建置的靜態網站，可以直接開啟 `index.html`。若要模擬 GitHub Pages 的執行方式，建議使用本機 HTTP server：

```sh
python -m http.server 8000
```

然後前往 <http://localhost:8000>。

## 測試

需要 Node.js 20 或更新版本，不需安裝第三方套件：

```sh
npm test
```
